✎ Edit Locally

Plugin para editar mensagens de outros usuários localmente no Revenge

Como instalar

Use esta URL no Revenge para instalar o plugin:

https://snowzz0.github.io/Revenge-edit-local-message

Recursos

  • Edite mensagens de outros usuários localmente
  • As edições aparecem apenas para você
  • Suporta qualquer conteúdo de mensagem
  • Interface integrada ao Revenge
